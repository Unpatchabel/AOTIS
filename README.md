# AOTIS

## AI-Driven OSINT Threat Intelligence System

AOTIS is a cybersecurity project designed to assist security analysts by collecting, analysing, and enriching Open Source Intelligence (OSINT) data.

The goal of AOTIS is to create an AI-assisted threat intelligence platform capable of analysing Indicators of Compromise (IOCs), generating threat insights, and producing analyst-friendly reports.

---

# Project Vision

Modern SOC teams deal with large amounts of security data every day. AOTIS aims to reduce manual investigation time by combining:

- OSINT collection
- Threat intelligence enrichment
- Security automation
- AI-assisted analysis
- Attack scenario generation

The final system will help analysts understand:

- What a threat indicator is
- Whether it is malicious
- How it could be used in an attack
- What actions defenders should take

---

# Planned Features

## IOC Analysis

Support investigation of:

- IP addresses
- Domains
- URLs
- File hashes

---

## Threat Intelligence Collection

AOTIS will integrate with external intelligence sources to gather:

- Reputation information
- Malware associations
- Threat reports
- Domain information
- Network intelligence

Potential sources:

- VirusTotal
- AbuseIPDB
- WHOIS services
- Other OSINT platforms

---

## AI Threat Analysis

The AI component will analyse collected intelligence and generate:

- Threat summaries
- Risk assessments
- Attack scenarios
- Possible attacker behaviour
- Recommended defensive actions
